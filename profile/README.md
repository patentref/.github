# PatentRef

US patent data API that answers the PatentsView PatentSearch format. Grants since 1976, claims, citations, and maintenance-fee status with an as-of date. Free beta. Not affiliated with the USPTO.

- API and docs: https://patentref.io/?utm_source=github-org
- Migration from PatentsView: https://patentref.io/docs/migration.html?utm_source=github-org
- Full data snapshot (CC BY 4.0): https://doi.org/10.5281/zenodo.23250455
